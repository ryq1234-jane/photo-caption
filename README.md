# 사진 자막 넣기

사진에 자막을 넣고 이미지로 저장하는 웹페이지입니다.

👉 **https://photo-caption.vercel.app**

## 기능
- 여러 줄 자막 (글꼴, 크기, 색, 정렬, 줄 간격, 기울기)
- 외곽선, 배경색 (투명도·높이 조절)
- 자막을 끌어서 위치 옮기기
- 미리보기 확대/축소 (두 손가락, 마우스 휠, 두 번 탭)
- JPG / PNG / WebP 저장, 품질·크기 선택
- 휴대폰 화면 지원

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성 |
| `style.css` | 디자인 |
| `fonts.css` | 눈누 무료 폰트 불러오기 |
| `script.js` | 동작 |

## 배포
`main` 브랜치에 push하면 Vercel이 자동으로 배포합니다.
